# 🛍️ ShopEase – E-Commerce Database Management System



ShopEase is a responsive E-Commerce Database Management System developed as a DBMS mini project. The project demonstrates the core concepts of database design and e-commerce management through an interactive user interface.

Customers can browse products, explore categories, view product details, register, log in, manage shopping carts, and proceed to checkout. An administrator dashboard is also provided to manage products, customers, orders, and reports.

---

# 🎯 Objectives

- Develop a user-friendly e-commerce interface.
- Demonstrate DBMS concepts in a real-world application.
- Provide separate interfaces for customers and administrators.
- Simulate online shopping functionalities.
- Design a scalable system for future database integration.
