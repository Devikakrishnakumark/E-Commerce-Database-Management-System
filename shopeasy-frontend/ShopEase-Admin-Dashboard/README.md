# ShopEase Admin Dashboard

A six-view business management dashboard with sample data, Indian rupee formatting, inventory add/edit/delete, customer and order details, sales charts, filtering, and CSV exports.

## Run the downloaded app

1. Install Node.js 22 or newer and Bun.
2. Open a terminal in this folder.
3. Run `bun install`.
4. Run `bun run dev` and open the local address printed in the terminal.

This is a source-code download, not a standalone executable. Sample inventory changes last until the page is refreshed. No live backend, login, or production admin permissions are connected. The existing backend described in the supplied blueprint was not changed.
